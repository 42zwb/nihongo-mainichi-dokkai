# 每日日语阅读 | Daily Japanese Reading | 毎日の日本語読解

本仓库每日发布一篇日语阅读练习。当前只更新 N2 级别；未来可能增加其他级别。

This repository publishes one Japanese reading exercise each day. It currently covers N2 only; other levels may be added later.

このリポジトリでは毎日、日本語の読解教材を公開します。現在はN2レベルのみで、将来的にほかのレベルを追加する場合があります。

## 中文

文章根据近期全球新闻或有事实支撑的科学、社会、文化等主题重新组织并原创撰写，不直接复制来源原文。正文约 800–1200 个日文字符，以 N2 难度为主，可少量包含 N1 词汇或语法。每篇提供可独立打开的 HTML，包含日语正文与注音开关、全文中文翻译、重点词汇和语法讲解，以及 3 道仿 JLPT 长文阅读形式的选择题。读者可选择答案、提交核对，并查看正确答案及其在原文中的依据。文章来源会列在页面末尾。

每日文章位于 N2 level/，文件按 YYYY-MM-DD.html 命名。

## English

Articles are original rewrites based on recent global news or evidence-based topics in science, society, culture, and related fields; source text is not copied. The main text is about 800–1,200 Japanese characters and is primarily N2 level, with occasional N1 vocabulary or grammar. Each standalone HTML includes Japanese text with a furigana toggle, a full Chinese translation, vocabulary and grammar notes, and three JLPT-style long-reading multiple-choice questions. Readers can select answers, submit them for checking, and see the correct answers with evidence linked to the passage. Sources are listed at the end of each article.

Daily articles are stored in N2 level/ and named YYYY-MM-DD.html.

## 日本語

記事は、最近の世界ニュースや、科学・社会・文化などの根拠あるテーマをもとに再構成したオリジナル文章です。情報源の文章をそのまま転載しません。本文は約800～1200字で、N2レベルを中心とし、N1の語彙や文法を少し含む場合があります。各HTMLは単独で開くことができ、日本語本文とふりがな表示切替、全文中国語訳、重要語彙・文法の解説に加え、JLPTの長文読解を参考にした選択問題を3問収録します。選択して解答を確認でき、正解と本文中の根拠も表示します。参考資料は各記事の末尾に記載します。

毎日の記事は N2 level/ に保存し、ファイル名は YYYY-MM-DD.html とします。
