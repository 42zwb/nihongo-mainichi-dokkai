# N2 Level Reading Articles

## 中文
本目录保存每日更新的 N2 日语阅读材料。文章正文约 800–1200 个日文字符，优先选取近期新闻或有具体依据的主题并原创改写。每篇 HTML 提供固定位置的注音开关、Noto Sans JP 正文字体、全文中文翻译、重点词汇和语法讲解，以及 3 道仿 JLPT 长文阅读形式的交互选择题。题目支持选项点选、提交核对、显示答案和原文出处。参考资料列于各篇末尾。

文件名格式：YYYY-MM-DD.html。打开 HTML 后可直接阅读和作答；注音按钮固定在视口中。

## English
This directory contains the daily N2 Japanese reading materials. Each original article is about 800–1,200 Japanese characters and is based on recent news or another well-sourced topic. Every HTML includes a viewport-fixed furigana toggle, Noto Sans JP body text, a full Chinese translation, vocabulary and grammar notes, and three interactive multiple-choice questions modeled on JLPT long reading. Questions support selection, answer checking, and display of the correct answer with passage evidence. Sources appear at the end of each article.

Files use the YYYY-MM-DD.html naming format. Open an HTML file to read and answer the questions; the furigana toggle stays fixed in the viewport.

## 日本語
このディレクトリには、毎日更新するN2レベルの日本語読解教材を保存します。本文は約800～1200字で、最近のニュースや具体的な根拠のあるテーマをもとに独自に書き直します。各HTMLには、画面に固定されたふりがな切替ボタン、Noto Sans JPの本文フォント、全文中国語訳、重要語彙・文法の解説、JLPT長文読解を参考にした選択問題3問を掲載します。選択、解答確認、正解表示に対応し、本文中の根拠も示します。参考資料は各記事の末尾にあります。

ファイル名は YYYY-MM-DD.html です。HTMLを開けば読解と解答ができ、ふりがなボタンは画面上に固定されます。
